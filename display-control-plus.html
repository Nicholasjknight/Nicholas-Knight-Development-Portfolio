Known Limitations

Worth knowing before you install, so per-monitor protection is the right fit for your setup.

Windows only

Display Control+ is a Windows desktop utility. There is no macOS or Linux build.

Not a permanent free tool

New installs get a 14-day trial, then require an annual subscription or lifetime license to keep running — it is not open-ended freeware.

Moved media breaks saved paths

Image and video overlay selections persist as file paths. If a referenced file is moved or deleted, the setting stays but the media won’t load until the path is corrected.

Licensing needs connectivity

Local protection itself runs offline, but activation, billing portal access, and account restore require a connection to the hosted licensing service.

Display Control+ FAQ

Common questions before installing a multi-monitor protection utility.

Is Display Control+ free?

New installs get a 14-day free trial. After that, continued use requires an annual subscription or a one-time lifetime license through Stripe checkout.

Which executable should I actually run?

tray.exe. It is the recommended entry point for daily use. DisplayControl.exe opens the dashboard directly if you need it, and overlay_bg.exe is a background process the tray app manages for you.

Do my settings survive a restart?

Yes. Configuration is stored in %APPDATA%\KnightLogics\DisplayControlPlus\config.json, and license/account state is stored separately in license.json in the same folder.

Can I run different protection rules on different monitors?

Yes. Per-monitor profiles let one display use a fast timeout while another uses a longer one, with mixed-timeout reliability improved in v1.1.1.
