# Service-area content images

Hero sections on city pages use the **shared Knight Logics hero pattern** (gradient + form — no per-city hero photograph).

These WebP files are **in-article** metro context images only (first figure inside the article body). JPG sources remain on disk as originals.

| File | Notes |
|------|--------|
| `tampa.webp` … `plant-city.webp` (20 files) | Royalty-free Unsplash stock downloads used as unique per-page content images. Replace with true city photographs when available. |

Sources were fetched via Unsplash image CDN (`images.unsplash.com`) during build. See `scripts/service-areas/download-city-images.js` for URLs.
