The Build

HTML5 CSS3 Vanilla JS GitHub Pages Intentional noindex

The Demo Preview tier ($200) is purpose-built for businesses that need a sales demo without a custom domain or search indexing. It answers: “Can we show what this could look like this week?”

Farrell Electric is a portfolio sample: Facebook photos gathered and turned into a custom-coded GitHub Pages demo for a friend who chose not to move forward with a paid engagement. No custom domain. Not submitted for search — GitHub Pages can be indexed, so Demo Preview deliberately stays non-search.

This tier skips domain, GBP, analytics, and deep SEO while focusing on conversion clarity: offer, services, work photos, and a contact path.

As a Demo Preview example, it is the lowest-risk entry into custom-coded presence — ideal before Preview Launch, Local Site, or a Growth System.

What Was Delivered

  • Three custom HTML pages with responsive design
  • HTML5 semantic markup for accessibility
  • Basic SEO meta tags (title, description, OG, Twitter Card)
  • Electrician schema (JSON-LD) for service type identification
  • Contact form with email routing
  • Services section with clear offerings
  • Work/portfolio gallery showing completed projects
  • Service area and geographic coverage
  • About section for trust and credibility
  • Hamburger navigation for mobile
  • Mobile-responsive layout (no desktop-only design)
  • Deployed on free GitHub Pages hosting

What's Not Included

  • Custom domain (hosted on GitHub Pages URL)
  • Search indexing / Search Console submission (intentional noindex)
  • Google Analytics or Microsoft Clarity
  • Google Business Profile setup
  • Deep content architecture (service clusters, city-page network, blog)
  • Advanced SEO foundation (keywords, local indexing focus)
  • Directory registration or citation work
  • Bing Webmaster setup
  • Local-specific service pages

Ideal For

Demo Preview is Right When:

  • You need a sales demo this week, not a ranking website
  • You do not want a custom domain or search indexing yet
  • You have photos (Facebook, phone) and a rough offer to validate
  • You're testing market demand before heavier investment
  • Most lead flow is still word-of-mouth or direct referrals
  • You want $200 credit toward a larger package later

Next step: When you need multi-page depth, a custom domain, or Google visibility, move to Preview Launch or Local Launch.

Demo Preview Disclosure

Read this before you assume Farrell Electric is a paid client result

To be direct: this is not a live client case study, and Farrell Electric is not a paying customer of Knight Logics. It is a demo preview — a $200-tier, custom-coded sales sample assembled from a friend's Facebook photos to show what a fast, credible starting point could look like. The friend did not move forward with a paid engagement, and the site was never intended to rank in search.

We keep it in the portfolio anyway because it is honest proof of craft at the lowest tier we offer — three clean pages, real HTML/CSS, working schema, and a working contact form, built quickly and hosted for free. If you are comparing this page to a full growth system like Roof Monsters or Knight Group, you are comparing two different products on purpose; Demo Preview is the entry point, not the ceiling.
