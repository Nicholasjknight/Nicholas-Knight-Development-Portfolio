System Requirements & Two Ways To Run It

VideoForge Studio ships two install paths. Almost everyone should use the packaged Windows build below; source mode exists for anyone who wants to run it directly from Python.

Recommended: Packaged Windows Build

Bundled Python + FFmpeg — nothing else to install

Download the installer or the portable exe zip from GitHub Releases. Both include a bundled Python runtime plus bundled ffmpeg.exe and ffprobe.exe, so there is nothing separate to install. Extract the zip, run VideoForge-Studio.exe, and the app opens in its own desktop window backed by a local render server on your machine.

Operating system Windows 10 or Windows 11, 64-bit
Dependencies None — Python runtime and FFmpeg/ffprobe are bundled in the packaged build
Fallback access If the desktop window doesn’t open, the same UI is reachable at http://127.0.0.1:5050 in a browser

Source Mode (Advanced / Dev)

  • Windows 10 or 11
  • Python 3.12 installed, added to PATH
  • FFmpeg installed and available on PATH
  • Run install_videoforge.bat, then start_videoforge.bat

What Drives Render Time

  • Number and length of clips in the sequence
  • Output resolution and selected frame rate
  • Whether narration or timed captions are generated
  • How many render jobs are running at once on your machine

Known Limitations

Worth knowing before you download, so this is a good fit for what you actually need.

Windows only

There is no macOS or Linux build. Source mode still requires a Windows machine with Python 3.12 and FFmpeg on PATH.

Render speed depends on your hardware

Rendering is compute-heavy. Clip count, resolution, frame rate, and whether narration/captions are generated all affect how long a job takes on your machine.

Add-ons are optional, not required

Narration, credit billing, and email recovery are features that can be enabled — none of them are required to install the app or render local ranked exports.

Not a general-purpose editor

VideoForge builds ranked and countdown-style sequences from clips you provide. It is not a timeline editor for arbitrary video projects.

If the .exe won’t start

Run VideoForge-Studio.exe from a normal extracted folder like Desktop or Downloads — not from inside the zip. If the desktop window itself doesn’t open, set VIDEOFORGE_UI_MODE=browser and relaunch, or visit http://127.0.0.1:5050 directly.

VideoForge FAQ

Branded search answers for VideoForge / Video Forge Studio.

Is VideoForge Windows-only?

Yes. The public download is a Windows 10/11 installer. Hosted or Docker paths exist in the repo for operators, but this page sells the free desktop download.

Is there a subscription to download?

No. Install is free. Optional credit billing for add-ons uses the same Knight Account Stripe path as PixelForge when enabled — not required to render local ranked exports.

What does “ranked local video” mean?

You upload 3–10 clips, set titles/captions/overlays, and render a countdown or ranked showcase with FFmpeg on your machine — not a YouTube Shorts auto-reframe tool.

Does rendering ever run on Knight Logics servers?

No, not in the packaged desktop build. Rendering happens locally with the bundled FFmpeg on your own hardware — no render workload is sent to Knight Logics infrastructure unless you deploy the backend-ready stack yourself.

What output sizes does it support?

Portrait 1440×2560, landscape 1920×1080, or a custom size you set per render, with a frame-rate selector added in v0.4.4.

The .exe won’t start — what do I try first?

Extract the zip fully and run VideoForge-Studio.exe from a normal folder like Desktop or Downloads, not from inside the compressed zip. If the desktop window still doesn’t open, the app is also reachable at http://127.0.0.1:5050 in a browser.
